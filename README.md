## ملاحظات على كل أداة
أداة Claude:

أعطت كوداً كاملاً ومتكاملاً يعمل مباشرة من المرة الأولى خلال دقيقة و نصف فقط 

صممت واجهة مستخدم جميلة واحترافية باستخدام CSS متقدم

أضافت تعليقات واضحة داخل الكود لتوضيح كل جزء

قامت بمعالجة الأخطاء المحتملة مثل إدخال المستخدم لأحرف بدلاً من أرقام

الكود كان منظماً وسهل القراءة والتعديل 

أداة Google Gemini:

أعطت كوداً يعمل لكن مع وجود خطأ بسيط في حساب أسعار الصرف تم تعديله يدوياً و استغرفت مدة تنفيذ الطلب بضع ثواني معدودة

التصميم كان بسيطاً وأساسياً ولكنه يؤدي المطلوب 

لم تضف تعليقات كافية داخل الكود

لم تتضمن معالجة للأخطاء المحتملة تمت معالجة الاخطاء بتوجيه جيمني بالمطلوب و الاوامر 

الكود كان أقل تنظيماً مقارنة بـ Claude
